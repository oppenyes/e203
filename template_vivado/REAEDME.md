# 项目构建指南

本项目是基于 Vivado 的 FPGA 工程，包含 RTL 源文件、约束文件以及自动化生成的 IP 核文件。以下提供了项目的使用说明和 `Makefile` 指令功能简介。

---

## 文件夹结构说明

```plaintext
├── constrs/         # 存放 XDC 约束文件
├── ip/              # IP 核生成文件的存放目录（会自动清理）
├── obj/             # 中间生成文件目录（如 BIT/MCS 文件）
├── script/          # TCL 脚本目录，包括 board.tcl 和生成的 IP 脚本
├── src/             # RTL 源代码文件目录
├── Makefile         # 项目构建的核心文件
```

---

## 使用步骤

1. **生成 IP 核脚本**
   - 在 Vivado 中运行以下命令，将项目中的所有 IP 核生成为 TCL 脚本：
     ```tcl
     write_ip_tcl -force [get_ips] create_ip.tcl
     ```
   - 将生成的 `create_ip.tcl` 文件移动到 `script` 文件夹中。

## Makefile 指令说明

| 指令            | 功能                                                                 |
|-----------------|----------------------------------------------------------------------|
| `make check`    |                   |
| `make clean_ip` | 清理 `ip/` 文件夹中的所有内容，避免生成过多无用文件。                |
| `make clean`    | 清理项目中的中间文件、日志文件以及 Vivado 生成的相关临时文件。        |
| `make init`     | 初始化项目，加载脚本并生成初步的 `.bit` 文件。                        |
| `make bit`      | 生成最终的 `.bit` 文件，包含设计的完整实现。                         |
| `make mcs`      | 生成用于编程的 `.mcs` 文件（依赖 `.bit` 文件）。                     |
| `make setup`    | 执行 setup 脚本阶段的初始化，用于设置 Vivado 环境。                  |

---

## 注意事项

- **确保路径正确**：
  - 所有 RTL 文件、约束文件以及脚本必须放在对应的文件夹中。
  - 脚本中的路径必须正确指向 `src`、`constrs` 等文件夹。
  
- **Vivado 版本兼容性**：
  - 请使用与脚本生成时相同的 Vivado 版本（如 `2020.2`），以避免版本不兼容问题。

- **IP 文件夹的清理**：
  - 每次运行 `bit` 命令前会自动清理 `ip` 文件夹，避免生成过多文件。
